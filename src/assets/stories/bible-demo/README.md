# Демо «Библейского компьютерного справочника» в браузере

Оригинальная демо-версия программы 1996 года (`rbible.exe`, Windows 3.1), запущенная в браузере
через [Boxedwine](https://github.com/danoon2/Boxedwine) — Wine, собранный в WebAssembly. Windows не используется.

Страница для встраивания — `index.html`, в тексте она подключается через `<iframe>`.

## Что здесь лежит

| Файл | Что это |
| --- | --- |
| `index.html` | Страница демо: экран программы, заставка загрузки, строка-подсказка |
| `rbible.zip` | Файлы программы из оригинального установщика и `rbkbd.exe` |
| `rbkbd.js` | Передаёт набранные на странице символы в программу |
| `helper/` | Исходник `rbkbd.exe` и скрипт сборки (`build.sh`, нужен clang и python3) |
| `boxedwine.js`, `boxedwine.wasm`, `boxedwine.zip`, `boxedwine.css` | Boxedwine 26R1, однопоточная веб-сборка, без изменений |
| `boxedwine-shell.js` | Загрузчик Boxedwine; изменена одна строка, помечена комментарием `rbible:` |

## Зачем нужен rbkbd

Boxedwine знает только американскую раскладку клавиатуры. `rbkbd.js` записывает набранные символы
в файл внутри эмулятора, а `rbkbd.exe` запускает `rbible.exe`, читает этот файл каждые 30 мс
и отправляет символы в активное окно.
Она же ставит окно программы по центру рабочего стола с полями по 32 пикселя.

Размер рабочего стола (960×630) задан параметром `resolution` в `index.html`; под него рассчитаны
пропорции блока `.longread__demo-screen` в стилях лонгрида.

Русский интерфейс программы включается русской локалью Wine (`LC_ALL=ru_RU.UTF-8` в `index.html`).
