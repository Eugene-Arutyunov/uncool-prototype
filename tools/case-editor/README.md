# Редактирование текста истории «С Божьей помощью» на странице

Запуск из корня проекта: `npm run edit` или `node tools/case-editor/server.cjs`.
Страница: http://127.0.0.1:4317/stories/s-bozhey-pomoshchyu/.

Кликни по абзацу, заголовку или пункту списка и исправь текст в обычной вёрстке сайта. Кнопка «Сохранить» или Cmd/Ctrl+S записывает изменения в `src/stories/s-bozhey-pomoshchyu.html`, пересобирает локальный предпросмотр и обновляет страницу. Черновые изменения автоматически сохраняются в этом браузере и восстанавливаются при повторном открытии той же версии исходника. Вставка допускает только обычный текст; Enter добавляет перенос строки.

Редактор привязывает каждый блок к точному месту в исходнике до рендеринга, поэтому одинаковые фразы не перепутываются. Разметка редактора добавляется только в отдельную сборку `_preview/case-editor-site/`; в исходник и обычную сборку сайта (`npm run dev`) она не попадает.

Перед сохранением создаётся копия исходника в `_preview/case-editor-backups/`. Чужие изменения исходника защищены проверкой версии. При ошибке сборки исходник восстанавливается. Сервер слушает только `127.0.0.1` и проверяет Host, Origin и токен записи. Публикация не выполняется.

Проверки: `node --test tools/case-editor/server.test.cjs`.
